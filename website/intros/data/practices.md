# What makes synthetic data good

If you read one page before generating data, read this one. It condenses what the open recipes actually did, with
the numbers they reported, into rules of thumb: seeds decide coverage, few question sources but many answers,
filtering is where quality is made, decontaminate before counting, and the only ground truth is a model trained on
the result.
