## 화면별 상세

### `/docs` — Swagger UI

**목적** — API 를 브라우저에서 호출해 config 검증과 Job 실행·조회를 한다.

**레이아웃** — FastAPI 기본 Swagger. 태그 순: Health, Config Channel, Job Channel, System Channel.

**데이터**

| 출처 | 호출 | 쓰이는 곳 |
|---|---|---|
| `/openapi.json` | GET | 전체 화면 |

**상태·파라미터**

| 이름 | 위치 | 기본값 | 효과 |
|---|---|---|---|
| — | — | — | 없음 |

**인터랙션**

| 사용자 행동 | 결과 |
|---|---|
| Try it out → Execute | 해당 엔드포인트 호출, 응답 표시 |

**빈 상태** — 해당 없음.

**에러 상태** — 서버가 내려가 있으면 브라우저 오류 페이지. 처리 없음.
